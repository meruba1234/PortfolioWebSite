プログラミング

CSV を手動で編集するときの注意点（かんたん版）

CSV ファイルを人の手で直したり、2つのファイルをつなげたりするときの注意点をまとめたもの。詳しい仕組みは CSV を手動で編集するときの落とし穴（詳細版） を参照。

1. 大原則 — CSV を Excel で開かない

CSV は「ただの文字が並んだテキストファイル」で、書式の情報を持っていない。 Excel はそれを勝手に解釈して書き換えてしまうため、開いて保存しただけでデータが壊れる。

元のデータExcel で開いて保存すると影響
00123123先頭のゼロが消える（コード類が全滅）
1-22001/1/2日付に変わる
12345678901234561.23457E+15指数表記になる／16桁目以降が 0 になる
(株)〇〇(株)〇〇ふりがな情報などが付加されることがある
Shift_JISUTF-8取込先で全部文字化け

「見るだけ」でも危険。 開いた後にうっかり保存すると壊れる。

2. 中身を見たい・直したいときはメモ帳で開く

メモ帳（またはサクラエディタ、VSCode）なら、値を勝手に変換しない。これが最大の利点。

開き方: CSV ファイルを右クリック → 「プログラムから開く」 → 「メモ帳」

3. メモ帳で編集するときの3つの注意

① 文字コードを変えない ウィンドウ右下に ANSI / UTF-8 などの表示がある。開いたときの表示を覚えておき、保存後も同じか確認する。 社内の基幹システムが出す CSV はたいてい ANSI（＝Shift_JIS）。これが UTF-8 に変わると、取込先で全部文字化けする。

② 1行目（見出し行）を触らない ［データ区分］,［伝票日付］,... のような1行目は見出し。消したり増やしたりしない。

③ カンマの数を変えない 1行あたりのカンマの数は全行同じでなければならない。値の中にカンマを入れると列がずれるので、入力する値にカンマを含めない（1,000 ではなく 1000）。

4. 2つの CSV をつなげたいとき

やり方: 1つ目のファイルの末尾に、2つ目のファイルの2行目以降（見出し行を除いた部分）を貼り付ける。

つなげるときのチェック:

  • [ ] 2つのファイルの見出し行が完全に同じか
  • [ ] 2つ目の見出し行を消したか（消し忘れるとデータの途中に見出しが混ざる）
  • [ ] 貼り付けた境目で行がくっついていないか（...20260731D,20260731,... のようになっていたらNG）
  • [ ] 完成後の行数が「Aの行数 ＋ Bの行数 − 1」になっているか

手作業に自信がないときは、電算部に依頼すれば数分でつなげられる。行数・列数・重複のチェックまで含めて実施する。

5. 編集が終わったら必ず確認する3つ

  1. 行数 — 想定どおりか（メモ帳の「表示 > ステータスバー」で行番号が見える）
  2. 文字コード — 開いたときと同じか（右下の表示）
  3. 列のズレ — 最終行あたりをいくつか見て、カンマの数が揃っているか

6. いちばん大事なこと

編集する前に、必ず元ファイルをコピーして残す。

発注データ.csv           ← 原本（触らない）
発注データ_編集用.csv     ← こっちを編集する

CSV の事故は「壊れたことに後から気づく」パターンがほとんどで、原本がないと復旧できない。コピーさえ残っていれば、何をやり直してもよい。

困ったら

  • 開いたら1列にまとまって表示される → 同じフォルダの「CSV_Excel表示トラブル解説_v2.docx」を参照（区切り位置で直せる）
  • 文字化けした / コードのゼロが消えた → 保存せずに閉じて、原本からやり直す
  • つなげ方・分け方がわからない → 電算部へ。件数が多いほど手作業より確実で早い
