Web技術

クライアント側フィルタ vs サーバ側フィルタの判断

背景

一覧画面に検索ボックスや絞り込み条件（カテゴリ、期間、ステータスなど）を付けるとき、「その絞り込みをブラウザ側でやるか、サーバ側でやるか」を必ずどこかで決めることになる。

  • クライアント側: 全件を一度サーバから取ってきて、以降の検索・絞り込みはブラウザの JavaScript（例: applySearch()）で完結させる。
  • サーバ側: 検索条件を変えるたびにサーバへリクエストを投げ、絞り込み済みのデータだけを受け取る。

どちらも「正しく絞り込める」点は同じなので、判断軸は正しさではなく データ量・権限・鮮度・体感速度 になる。ここを最初に決めておかないと、後から作り直しになりやすい。

クライアント側が向くケース

以下が揃うほどクライアント側フィルタが有利になる。

  • データ量が小さい — 全件がブラウザに無理なく載る（目安として数MB程度に収まる）。
  • 検索条件を頻繁に変える — キーワードを打ち替えたり、チェックを付け外ししながら何度も絞り込む使い方。
  • 行レベルの権限分けが不要 — 誰が見ても同じ全件が見えてよい。

この条件なら、最初に一度だけ全件を取得しておけば、あとは サーバへ行かずにブラウザ内で applySearch するだけなので、都度リクエストの往復（ネットワーク遅延）が発生せず体感がとても速い。インクリメンタルサーチのように「1文字打つたびに結果が変わる」UI とも相性がよい。

サーバ側が向くケース

逆に、次のどれかに当てはまるならサーバ側で絞り込むべき。

  • データが大量 — 全件をブラウザに送れない／送ると重い。ページング前提の一覧。
  • 行レベル権限がある — ユーザーごとに見えてよい範囲が違う。全件をブラウザに渡すと、画面に出していないだけで手元には全データがある状態になり、情報漏れになる。
  • 最新性が厳しい — 常に最新の状態を見せたい。手元にキャッシュした古い全件では困る。
  • SEO が要る — 検索エンジンにインデックスさせたい公開ページ。サーバが絞り込み済みの HTML を返す必要がある。

特に 権限 は「速いから」で妥協してはいけない軸。速度のためにクライアント側に全件を渡すと、権限の壁を UI の見た目だけで作ることになり、開発者ツールで中身が丸見えになる。

トレードオフ整理

観点クライアント側サーバ側
初回転送量大（全件を一度に送る）小（絞り込み後だけ）
都度リクエスト不要（ブラウザ内で完結）条件変更ごとに発生
体感速度（絞り込み時）速い（往復なし）ネットワーク遅延の分だけ待つ
ブラウザのメモリ全件を保持するので多く使う少なくて済む
行レベル権限苦手（全件が手元に渡る）得意（サーバで絞れる）
鮮度（最新性）取得時点で固定されやすい常に最新を返せる
データ量への強さ小規模向き大規模でもスケール

要するに 「初回にまとめて払うか（クライアント）／使うたびに少しずつ払うか（サーバ）」 のコスト配分の違いと、そこに 権限と鮮度という妥協できない要件が乗ってくる、という構図で捉えるとよい。

ハイブリッドという現実解

実務では二択ではなく、組み合わせることが多い。

  • サーバで粗く絞る — 期間・部署・担当など、母集合を現実的なサイズまで落とす条件はサーバ側で処理する。
  • クライアントで細かく絞る — その結果セット（数百〜数千件程度）に対して、キーワード検索や細かいチェックボックス絞り込みはブラウザ側で高速に行う。

こうすると「全件は送らない（権限・データ量の問題を回避）」かつ「細かい絞り込みは往復なしで速い」という両方のいいとこ取りができる。まず粗いサーバ絞りの単位（期間や部署など、自然な区切り）を決めてから、その中でクライアント絞りを設計するのが定石。

関連: ファセット整合性（別テーマ）

絞り込みの選択肢（ファセット。カテゴリ一覧やタグ一覧など）を どの母集合から作るか と、実際に結果を絞る条件がずれると、「選択肢に出ているのに選ぶと0件」という不親切な状態が起きる。これは client/server の判断とは別の設計論点なので、ここでは深入りせず、別ノートで扱う。

まとめ

  • 判断軸は正しさではなく データ量・権限・鮮度・体感速度。
  • 小規模・高頻度検索・権限不要 → クライアント側（全件取得して往復なしで速く絞る）。
  • 大量・行レベル権限・最新性・SEO → サーバ側（絞り込み後だけ返す）。
  • 権限と鮮度は速度と引き換えにしてはいけない軸。特に全件をブラウザに渡す設計は情報漏れに直結する。
  • 実務では サーバで粗く→クライアントで細かく のハイブリッドが有力。まず粗い絞りの単位を決める。
