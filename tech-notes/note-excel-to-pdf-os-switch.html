インフラ

Excel → PDF 変換を OS で切り替える（win32com / LibreOffice headless）

背景

帳票を xlsx で組み立てて PDF で配布したい、という要件はよくある。このとき困るのが「開発は Windows、本番は Linux」という環境差だ。手元の Windows では Excel 本体が入っているので何とでもなるが、本番のジョブ実行基盤が Linux コンテナだと Excel は使えない。それでも同じ xlsx から同じような PDF を出したい。

ここで整理しておきたいのが、xlsx の生成と PDF 化はまったく別工程だということ。生成は openpyxl でクロスプラットフォームに書けるが、PDF 化は OS ごとに手段を切り替える必要がある。

openpyxl では PDF 化できない

まず前提。openpyxl は xlsx を「作る・読む・書き換える」ライブラリで、 PDF 出力の機能は持っていない。セルの値・書式・グラフ・画像までは扱えるが、最終的な紙面レイアウト（ページ分割・印刷倍率）をレンダリングして PDF に固める処理は範囲外だ。

PDF にするには、xlsx を実際に「開いて印刷レイアウトを確定できるもの」が要る。選択肢は主に2つ。

  • Excel 本体（COM 経由） — Windows のみ
  • LibreOffice（headless モード） — Windows / Linux 両方で動くが本番では Linux で使う

つまり役割分担はこうなる。

工程使うものプラットフォーム
xlsx の生成・編集openpyxlWindows / Linux 共通
xlsx → PDF 変換Excel COM または LibreOfficeOS で切替

OS で手段を切り替える

実装としては「OS を判定して変換手段を分岐する」1関数にまとめておくと扱いやすい。

import platform
import subprocess
from pathlib import Path


def xlsx_to_pdf(xlsx_path: Path, out_dir: Path) -> Path:
    """xlsx を PDF に変換する。OS で手段を切り替える。"""
    if platform.system() == "Windows":
        return _convert_with_excel_com(xlsx_path, out_dir)
    else:
        return _convert_with_libreoffice(xlsx_path, out_dir)

Windows: win32com（Excel COM）

Windows では Excel を COM オートメーションで裏起動し、ExportAsFixedFormat で PDF を吐く。

import win32com.client as win32


def _convert_with_excel_com(xlsx_path, out_dir):
    pdf_path = out_dir / (xlsx_path.stem + ".pdf")
    excel = win32.gencache.EnsureDispatch("Excel.Application")
    excel.Visible = False
    excel.DisplayAlerts = False
    # 元ファイルを直接開かず、ReadOnly で開いて巻き込み事故を防ぐ
    wb = excel.Workbooks.Open(str(xlsx_path), ReadOnly=True)
    try:
        # 0 = xlTypePDF
        wb.ExportAsFixedFormat(0, str(pdf_path))
    finally:
        wb.Close(SaveChanges=False)
        # ここで excel.Quit() を安易に呼ばない（後述）
    return pdf_path

Linux: LibreOffice headless

Linux では LibreOffice を GUI なし（headless）で叩く。CLI 一発で変換できる。

def _convert_with_libreoffice(xlsx_path, out_dir):
    subprocess.run(
        [
            "libreoffice", "--headless",
            "--convert-to", "pdf",
            "--outdir", str(out_dir),
            str(xlsx_path),
        ],
        check=True,
    )
    return out_dir / (xlsx_path.stem + ".pdf")

CLI 部分だけ取り出すとこうなる。

libreoffice --headless --convert-to pdf --outdir <出力ディレクトリ> <入力.xlsx>

--outdir で出力先ディレクトリを指定する点に注意。出力ファイル名は入力の拡張子を .pdf に変えたものになる。同名 PDF が既にあると上書きされる。

ページ縮尺の副作用に注意

「1ページに収めたい」と思って印刷設定でこうしがちだ。

ws.page_setup.fitToWidth = 1
ws.page_setup.fitToHeight = 1
ws.sheetPr.pageSetUpPr.fitToPage = True

FitToPagesWide/Tall = 1 は「横1ページ・縦1ページに押し込む」指定で、はみ出す分はフォントが自動縮小されて 1 枚に収まる。表が横に長いと文字がどんどん小さくなり、印刷すると読めない、という失敗につながる。

対策は「縮尺で潰す」前に「入るスペースを増やす」こと。余白を極小化して、フォントを底上げするほうが読みやすい PDF になる。

ws.page_margins.left = 0.2
ws.page_margins.right = 0.2
ws.page_margins.top = 0.3
ws.page_margins.bottom = 0.3
ws.page_margins.header = 0.1
ws.page_margins.footer = 0.1

余白を削って本文フォントを上げ、それでも収まらない分だけ縮尺に頼る、という順番で考える。

COM 利用時の注意（ユーザーの Excel を巻き込まない）

win32com は結局のところ裏で Excel という GUI アプリを起動している。ここで雑に扱うと、ユーザーが手で開いている Excel まで一緒に閉じてしまう事故が起きる。

  • 元ファイルを直接開かず、一時コピーを ReadOnly で開く。編集ロックや上書きの巻き込みを避ける。
  • Application.Quit() を安易に呼ばない。同じ Excel プロセスをユーザーが共有していると、開いていたブックごと落ちる。閉じるのは自分が開いたブックだけ（wb.Close()）にとどめる。
  • DisplayAlerts = False で保存ダイアログ等のブロッキングを抑止する。

このあたりは Office の COM オートメーション全般に共通する注意点で、 PowerPoint など他の Office アプリでも同じ考え方が要る（自分が開いたものだけ後始末する）。

LibreOffice はレイアウトが微妙にずれることがある

LibreOffice は Excel と別実装なので、フォントの持ち方や細かなレイアウトが Excel とぴったり同じにはならないことがある。よくあるずれの原因。

  • Excel 標準フォント（游ゴシック等）が Linux 側に無く、代替フォントに置き換わる → 文字幅が変わり行が折り返す
  • セル幅の自動調整・改ページ位置が Excel と微妙に違う
  • 罫線や図形の位置が数ピクセルずれる

そのため、レイアウトが厳密に決まっている帳票（枠にきっちり収める請求書・伝票類）は、本番と同じ LibreOffice で一度 PDF を出して目視検証しておくべきだ。「Windows で見た目 OK だから Linux でも OK」とは限らない。必要なフォントは Linux コンテナ側にもインストールしておく。

まとめ

  • xlsx の生成は openpyxl（OS 共通）だが、PDF 化はできない。別の手段が要る。
  • PDF 化は OS で切り替える。Windows は win32com（Excel COM の ExportAsFixedFormat）、 Linux は LibreOffice headless（--convert-to pdf）。1関数に分岐を閉じ込めると扱いやすい。
  • FitToPages=1 はフォント自動縮小の副作用がある。余白を削ってフォントを底上げしてから縮尺に頼る。
  • COM は裏で GUI アプリを動かすので、一時コピーを ReadOnly で開く／自分のブックだけ閉じる。 Quit() を安易に呼ばない。
  • LibreOffice は Excel とレイアウトが微妙にずれる。厳密な帳票は本番環境で PDF を出して検証する。
