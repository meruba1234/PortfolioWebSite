Windows管理

Windows Update トラブルシューティング

学んだきっかけ

KB5083769 (2026-04) のインストールがエラー 0x80073712 で繰り返し失敗。各種修復手順を試した。

エラーコード 0x80073712

意味： コンポーネントストアの破損（Component store corruption）

Windowsのシステムファイルが壊れていて、更新プログラムが正しくインストールできない状態。

修復手順（段階的に試す）

1. DISM + sfc（まず試す）

DISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow
  • DISM: Windows Updateから正しいファイルをダウンロードしてコンポーネントストアを修復
  • sfc: システムファイルをスキャンして破損を修復
  • DISMを先に実行すること（sfcが参照するストアを先に直す必要がある）

2. Windows Updateキャッシュのクリア

net stop wuauserv
net stop bits
rd /s /q C:\Windows\SoftwareDistribution
net start wuauserv
net start bits
  • ダウンロード済みの壊れた更新ファイルを削除して最初からやり直す

3. Microsoft Updateカタログから手動インストール

  • https://www.catalog.update.microsoft.com/ からKB番号で検索
  • OS・アーキテクチャに合った .msu ファイルをダウンロード
  • ダブルクリックでインストール（Windows Updateを経由しない）
  • Microsoftの公式サイトなので安全

4. ISOを修復ソースとしてDISM（有効な手段）★実戦で成功

通常のDISMはWindows Updateから修復ファイルを取得するが、Windows Update自体が壊れていると修復できない悪循環に陥る。その場合、ISOのinstall.wimを修復ソースとして指定すれば、ISO内のクリーンなシステム部品で修復できる。

手順
  1. Windows 11 ISOをダウンロード（Microsoft公式）
  • https://www.microsoft.com/ja-jp/software-download/windows11
  • ファイルサイズ約8GB
  1. ISOをマウントまたは7-Zipで展開

```powershell # マウント（通常はこちら） Mount-DiskImage -ImagePath "C:\path\to\Win11.iso"

# マウント失敗時は7-Zipで展開 & "C:\Program Files\7-Zip\7z.exe" x "C:\path\to\Win11.iso" -o"C:\Win11ISO" -y ```

  1. install.wimのインデックス確認（OSエディションに合わせる）

``powershell Get-WindowsImage -ImagePath "C:\Win11ISO\sources\install.wim" ``

  • Index 1: Home
  • Index 3: Pro（一般的な業務PC）
  • Index 5: Pro for Workstations
  1. DISMで修復（ISOを修復ソースに指定）

``cmd dism /online /cleanup-image /restorehealth /source:wim:C:\Win11ISO\sources\install.wim:3 /limitaccess ``

  • :3 = Pro のインデックス
  • /limitaccess = Windows Updateを使わずISOのみを使う
  1. sfc /scannow で仕上げ
  1. 終了後、ISOとフォルダは削除してストレージ確保
この方法が有効な理由
通常のDISM: Windows Update → 修復ファイル取得 → 修復
　　　　　  （でも壊れてて失敗）

ISO指定DISM: ISOのinstall.wim → クリーンな修復ファイル → 修復成功

ISOは「Windowsの健康な部品の引き出し」として使うだけ。OSの再インストールではなく、壊れた部品だけ交換するイメージ。所要時間は10〜20分。

5. インプレースアップグレード（最終手段）

  • 設定 → システム → 回復 → 「今すぐ再インストール」
  • Windowsのシステムファイルを全部入れ直す
  • アプリ、データ、設定は基本的にそのまま残る
  • 所要時間：30分〜1時間
  • 業務時間外に実施すること

Windows Updateログの確認方法

# ログファイルを生成（デスクトップにWindowsUpdate.logが出力される）
Get-WindowsUpdateLog

# エラーコードで絞り込み
findstr /i "0x80073712" C:\Users\%USERNAME%\Desktop\WindowsUpdate.log

「今すぐ再インストール」は何をするのか

入れ直されるものそのまま残るもの
Windowsシステムファイルインストールしたアプリ
Windows標準アプリデスクトップ・ドキュメントのファイル
ユーザーアカウント・パスワード
ネットワーク設定
証明書ストア

注意： 一部のWindows設定やデバイスドライバーがリセットされる可能性あり

放置するという選択肢

  • 次の月例パッチ（翌月）で累積更新に含まれて自然に解決されることも多い
  • 急ぎでなければ無理に修復しなくてもよい

用語集

用語意味
コンポーネントストア（WinSxS）Windowsのシステム部品（DLL、設定等）が保存される倉庫。C:\Windows\WinSxS にある
DISMDeployment Image Servicing and Management。Windowsイメージ・コンポーネントストアの管理ツール
sfcSystem File Checker。システムファイルの破損を検出・修復するツール
サービシングスタックWindowsが更新プログラムを適用するための仕組み。これ自体が壊れると更新できなくなる
install.wimISOの中に入っている、Windowsの全システムファイルがまとまったイメージファイル
WIMイメージWindows Imaging Format。Windowsインストール用のイメージ形式
SoftwareDistributionWindows Updateがダウンロードした更新ファイルを一時保存するフォルダ。C:\Windows\SoftwareDistribution
0x80073712エラーコード「ERROR_SXS_COMPONENT_STORE_CORRUPT」= コンポーネントストア破損

実戦メモ：修復で注意すること

ストレージ不足に注意

  • ISO（8GB）+ 展開フォルダ（17GB）+ パッチ本体（5GB）で、最低でも30GB程度の空き容量が必要
  • 作業前にディスク使用量を確認すること
  • DISMが途中で失敗する原因にもなる

SoftwareDistribution削除時の注意

  • PowerShellの Remove-Item ではハードリンクの扱いで失敗することがある
  • cmdの rd /s /q の方が確実
  • 必ず先に net stop wuauserv と net stop bits でサービスを止める ``cmd net stop wuauserv net stop bits cmd /c "rd /s /q C:\Windows\SoftwareDistribution" net start wuauserv net start bits ``

最終的に効いた手順（2026-04-17〜18 実戦記録）

KB5083769 が何度も 0x80073712 で失敗 → 以下の手順で解決：

  1. DISM /RestoreHealth （通常版）→ 「完了」と出るが実は修復不十分
  2. sfc /scannow → ファイル修復
  3. Windows Update再試行 → 失敗継続
  4. ISOダウンロード（Windows 11 25H2 multi-edition）
  5. 7-Zipで展開（マウントが失敗したため）
  6. DISM /RestoreHealth /source:wim:...install.wim:3 /limitaccess → 成功
  7. sfc /scannow → 違反なし
  8. ISO・展開フォルダ削除（ストレージ確保）
  9. SoftwareDistribution削除（キャッシュリセット）
  10. Windows Update再試行 → KB5083769 インストール成功
