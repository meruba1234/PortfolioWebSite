自作プロジェクト計画: クリップ式ウェアラブルカメラ

目標

市販のクリップ式カメラ「KYOKUSAI 4K (TK-CLI-25)」のようなものを自作する。

お手本（市販品）のスペック

項目KYOKUSAI 4K
形状クリップ式（胸ポケット等に挟む）
サイズ/重量36×18×98mm / 61g
解像度4K (3840×2160) 30fps
レンズ180度回転式
録画microSD (〜512GB) に MP4、上書き録画
連続稼働約4.5時間（4K時）
通信Wi-Fi APモード（スマホアプリでプレビュー）
価格19,600円

先に正直な見積もり — DIYでどこまで寄せられるか

項目市販品DIY (ラズパイ案)差の理由
解像度4K30fps1080p30fps が現実線4K リアルタイムエンコードは専用 SoC（アクションカム用チップ）の仕事。Pi Zero 2 W のHWエンコーダは 1080p まで
サイズ/重量61g100〜150g 程度市販品は基板・電池・筐体を専用設計で詰めている
稼働時間4.5h3〜5h（2000mAh LiPo）ここはほぼ並べる
回転レンズ○○（3Dプリントで鏡筒を回す設計に）機構設計しだい
スマホプレビュー専用アプリPi を Wi-Fi AP 化 + ブラウザで MJPEG 表示同等機能を自作できる。むしろ学びどころ
価格19,600円部品代 約12,000円 + 工数安く作るのが目的ではなく中身を理解するのが目的

結論: 「4Kスペックの複製」は無理だが、「同じ機能構成の1080p版」は完全に自作可能。 録画・給電・筐体・無線プレビューの全要素を自分で設計するので、市販品の中で何が起きているかが全部わかるようになる。

構成案A: Raspberry Pi Zero 2 W 版（推奨・本命）

[Camera Module 3] ──FFC(きしめん)── [Pi Zero 2 W] ── [microSD: OS+録画]
                                        │
                  [LiPo 2000mAh] ─ [充電+5V昇圧ボード] ─ 給電
                                        │
                  [タクトスイッチ(録画開始/停止)] [LED(録画中表示)] ─ GPIO

部品リスト（概算 約12,000円）

部品目安価格備考
Raspberry Pi Zero 2 W3,300円クアッドコア、H.264 HWエンコーダ内蔵
Camera Module 34,500円IMX708、オートフォーカス付き、1080p50 対応
Zero 用 FFC (22pin→15pin)500円Zero はカメラコネクタが小さい。長さ違いを数本買うと筐体設計が楽
LiPo 2000mAh1,500円保護回路付きを選ぶ

製作ステップ（学習マイルストーン）

  1. 録画の最小構成 — Pi をヘッドレスセットアップし、rpicam-vid で 1080p30 の H.264 録画ができることを確認。
  2. ボタン起動化 — GPIO のタクトスイッチで録画開始/停止、LED で状態表示。systemd サービス化して「電源を入れたら待機」にする。市販品の「ボタン1つで録画」と同じ操作感を作る。
  3. 上書き録画（ループ録画） — 5分単位のファイル分割 + 容量が閾値を超えたら古いファイルから削除するスクリプト。ドラレコ・市販品の「上書き録画」の正体はこれ。
  4. バッテリー駆動 — LiPo + 昇圧ボードで給電し、実測で連続稼働時間を測る（録画中の消費電力 ≒ 1〜1.5W → 2000mAh/3.7V ≈ 7.4Wh で 4時間前後の見込み）。
  5. Wi-Fi AP + スマホプレビュー — Pi を AP モード化（NetworkManager / hostapd）し、MJPEG ストリーミングをブラウザ表示。市販品の「APモード専用アプリ」と同じ構成。
  6. 筐体設計 — 3Dプリントでクリップ + 回転鏡筒（カメラモジュールを円筒に入れ、筐体側の穴で保持して回す）。FFC は曲げRを緩く取って配線。

つまずきポイント（先回りメモ)

  • Zero 2 W は録画中そこそこ発熱する。筐体に通気スリットを。
  • LiPo の充電と放電を同時にやる回路（パススルー）は安いボードだと非対応。PowerBoost 系が楽。
  • microSD への 1080p30 書込みは U3 クラス必須。安カードはコマ落ちする。
  • 突然の電源断で録画ファイルが壊れる → 1〜5分でファイル分割しておけば被害が最小になる（市販品が分割録画なのも同じ理由）。

構成案B: ESP32-CAM 版（練習用・2,000円以下）

本命の前に「ボタンで録画してSDに保存」「Wi-Fiでプレビュー」の流れを 1,500円で一通り体験できる。画質は SVGA〜HD 相当でガタつくが、全体アーキテクチャの練習としては最高のコスパ。

[ESP32-CAM (OV2640+SDスロット内蔵)] + [LiPo 1000mAh] + [スイッチ]
  • CameraWebServer サンプル → ストリーミング即動作
  • avi 録画スケッチも公開例あり
  • ここで覚えたことがそのまま案Aに持ち上がる

構成案C: アナログFPVカメラ + ミニDVR（細さ最優先のとき）

「とにかく先端を細く」が目標になったときの選択肢。ドローン用 FPV カメラ（〜数g）+ 録画用ミニ DVR ボード。画質はアナログなり。今回のクリップ型なら不要だが、内視鏡的な形状にしたくなったら検討。

法律・モラル（再掲）

製品ページにも「防犯目的専用」とある通り、この種のカメラは使い方を誤ると盗撮規制（撮影罪・迷惑防止条例）に直結する。自作機の用途は自分の作業記録・自宅の防犯・機器点検等に限定し、撮影が他人に及ぶ場所では使わないこと。
