Web技術

言語とフレームワークの関係

言語とフレームワークの違い

  • 言語 = 文法そのもの（日本語、英語のようなもの）
  • フレームワーク = 言語の上に乗る「便利な書き方のルール集」（ビジネスメールのテンプレートのようなもの）

素の言語だけでも何でも作れるが、フレームワークを使うと「よくあるパターン」を効率よく書ける。

Web系の全体像

フロントエンド（ブラウザ側）

言語（素の技術）           フレームワーク/ライブラリ
─────────────────────────────────────────────────
HTML                    → （テンプレートエンジン: Blade, Jinja2）
CSS                     → Tailwind CSS, Bootstrap, SASS
JavaScript              → Alpine.js, React, Vue.js, jQuery
  • HTML/CSS/JS を学習済みなら基礎はできている
  • フレームワークは「よく使うパターンを楽に書くためのツール」

Dart                    → Flutter                      Android/iOS両対応

Java と Kotlin の関係

  • Java — 長年Androidアプリの標準言語だった
  • Kotlin — 2017年にGoogleがAndroidの公式言語として採用
  • KotlinはJavaと互換性があり、同じAndroid SDKの上で動く
  • Kotlinは言語であり、フレームワークではない（Javaの後継的な位置づけ）
  • 既にJavaでAndroidアプリを作った経験があれば、Kotlinへの移行はスムーズ
