実務で扱った技術

2025年9月〜2026年8月の社内SE業務での利用経験です。技術名だけでなく、担当した範囲を記載しています。

  • Python / SQL Server — 受発注データ処理、CSV連携、帳票生成、既存業務ロジックの移植、入力検証・ログ・通知。
  • Excel VBA / ADO — 入金消込の照合、DB取得・登録、受注振分け、確認画面・誤操作対策。
  • VB.NET — 既存コードの解析と仕様整理、Pythonへの段階的移植。新規VB.NET開発全般の経験を意味するものではありません。
  • Docker Compose / Prefect / Linux — 自動化基盤、スケジュール管理、段階移行、多重起動対策、障害時のログ確認・通知。
  • Laravel / Filament — 社内Webシステムの開発。Filament は Laravel / Livewire / Alpine.js / Tailwind CSS 系の構成として扱っています。
  • Flask / Vue.js / HTML / CSS — 社内Webツールの実装、FAX履歴の検索、業務情報の共有画面、異常受注・商品不足の一覧UI。

  • Playwright / API連携 — 業務サイトの画面操作、データ取得、kintone等との連携、社内チャット通知。
  • Java / Android — 物流業務向けアプリの開発。
  • Git / Amazon CodeCommit / AWS — ソース管理、AWS契約・導入対応。
  • Windows / PC・ネットワーク管理 — 約200台規模のPC資産管理、セットアップ・交換、問い合わせ・障害調査、機器保守。
  • Claude Code / Codex — 業務改善・開発、調査・実装・テスト・資料作成に活用。生成された資料はすべて読み、不明点はMarkdown形式の文書にまとめて復習。
  • C / PHP / MySQL / SQLite / JavaScript — 業務改善・開発での実務利用経験。

スキル記載の考え方

採用選考でご覧いただくことを想定し、経験の範囲を実際より広く見せないよう、以下の基準で記載しています。

  • React Native と React（Web）を同一視しない — React Native の利用経験はありますが、React による Web 開発の実務経験としては数えていません。
  • Filament を React 系の経験として数えない — Laravel / Livewire / Alpine.js / Tailwind CSS 系の技術として扱っています。
  • VB.NET は解析・移植が中心 — 既存コードの解読と Python への移植が主で、新規 VB.NET 開発全般の経験を意味するものではありません。
  • 実務年数を確認できない技術は「経験あり」と書かない — 求人でよく求められる技術であっても（例: Power Apps）、必要年数の実務を確認できないものは記載していません。

開発と学びの習慣

作成された資料はすべて自分で読み、内容を確認します。不明点は復習用の文書に整理し、後から読み直せるようにしています。資料の作成量が増えても、この習慣を欠かしません。

その復習ノートのうち、社内固有の情報を含まないものを 技術ノート として公開しています。
