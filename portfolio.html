社内SE × 業務自動化 × AI 活用

現場との対話から、業務改善を形にする

依頼されたものを作るだけでなく、自分から現場に声をかけて困りごと・使いづらさ・部門間連携の課題を確認し、 適切な改善方法を考え、必要な場合にシステムとして実装してきました。 要件整理から設計・実装・導入後の改善までを担当しました（前職・2025年9月〜2026年8月）。

対話 → 課題把握 → 業務改善を検討 → 必要ならシステム開発 → 導入・改善

複数案件を並行するときは、優先順位を付けてスピード感を持って進めます。 AI を業務に組み込んで開発スピードを上げ、現場の「面倒くさい」を「自動」に変えるのが好きです。

業務改善ケーススタディ

実際に取り組んだ業務改善案件を匿名化して 15 件のケーススタディとしてご紹介しています。本人集計による開発活動の記録は「実績データ」ページに掲載しています。 インフラ・業務自動化・取引先連携・レポート集計・既存システム移植・社内 Web ツール・照合・異常検知 など、 カテゴリ別に整理しています。担当範囲と設計上の判断を中心に紹介しています。

得意分野

  • 業務自動化基盤の構築 — Prefect / Docker / Python による社内ジョブ自動化
  • 既存システムの解読・移植 — VB.NET / VBA のリバースエンジニアリングと Python 化
  • 業務システム連携 — Web スクレイピング (Playwright) / API (kintone等) / DB (SQL Server)
  • AI を活用した開発 — Claude Code / Codex を調査・実装・テスト・資料作成の補助に活用
  • Excel + VBA + DB 連携 — 現場が使い慣れた Excel をフロントに、裏で DB と連動

開発と学びの習慣

Claude Codeを活用しながら業務改善・開発に取り組んできました。作成された資料はすべて自分で読み、内容を確認します。不明点は復習用の文書に整理し、後から読み直せるようにしています。資料の作成量が増えても、この習慣を欠かしません。

その復習ノートのうち、社内固有の情報を含まないものを公開しています。
